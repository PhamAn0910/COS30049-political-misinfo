2.1 ML & Inference Architecture

✓ Strength: Multi-Method ML Coverage
Plan correctly implements 4 ML methods across 3 types:
  • Classification: DistilBERT (primary) + TF-IDF + LogReg (baseline)
  • Clustering: Louvain Community Detection on PHEME user graphs
  • Regression: Ridge Regressor for cascade spread prediction
Strong justification for using 2 classification methods: baseline comparison is academically sound and demonstrates understanding of transformer superiority.
⚠ Critical Risk: PyTorch INT8 Quantization on Apple Silicon M3

Issue: The plan specifies INT8 dynamic quantization via torch.quantization.quantize_dynamic(), but PyTorch's quantization support on Apple Silicon MPS is incomplete and unstable.

Technical Invariant Violation:

  • MPS backend does NOT support quantized INT8 operations — quantized tensors fall back to CPU execution
  • CPU execution of quantized DistilBERT on M3 may be slower than FP32 MPS inference
  • Memory savings (250MB → 65MB) are valid, but inference latency may increase by 2-3×

Recommended Fix:

  1. Test quantized model inference latency BEFORE Assignment 2 submission
  2. If cold-start latency > 2 seconds, use FP16 instead: model.half().to('mps')
  3. FP16 on MPS: ~125MB RAM, faster inference than INT8 CPU
⚠ Architecture Gap: Model Lifecycle in FastAPI Lifespan

Plan correctly uses @asynccontextmanager async def lifespan(app) to load models on startup, but missing critical detail:

  • Tokenizer packaging: DistilBERT tokenizer files (~450KB) must be included in backend/models/
  • Path handling: Inference code must use pathlib.Path(__file__).parent for relative model paths
  • Error handling: If model load fails, FastAPI should raise startup exception, not serve 500s

  5. MEDIUM: Add React Error Boundary for Chart Components

    Assignment 3 rubric: "Error Handling & Validation" (3 pts). Implement frontend/src/components/common/ErrorBoundary.jsx: 

    import React from 'react';

class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  static getDerivedStateFromError(error) {
    return { hasError: true, error };
  }

  componentDidCatch(error, errorInfo) {
    console.error('Chart rendering error:', error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return (
        <div style={{ padding: '20px', border: '1px solid red' }}>
          <h3>Chart failed to render</h3>
          <p>{this.state.error?.message}</p>
          <button onClick={() => this.setState({ hasError: false })}>Retry</button>
        </div>
      );
    }
    return this.props.children;
  }
}

export default ErrorBoundary;
