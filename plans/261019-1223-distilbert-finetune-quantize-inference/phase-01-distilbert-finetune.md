# Phase 1: DistilBERT Fine-Tuning

## Goal
Fine-tune `distilbert-base-uncased` on the deduped splits and report how well it detects misinformation, both on
the random test split and on PHEME events it never saw, against the TF-IDF baseline.

**Where it runs:** the notebook is written locally (it stays the source of truth in the repo) and executed on a
Google Colab T4 GPU, driven from Claude Code through the `colab-mcp` server. The same notebook still runs locally
on MPS if Colab is unavailable.

- [x] Class weights from train counts, formula from the project plan:
      `w = 1 / counts; w = w / w.sum() * 2`; `CrossEntropyLoss(weight=w.to(device))`.

      id2label={0: "factual", 1: "misinformation"}, label2id=...)`.
- [x] `AdamW`, `get_linear_schedule_with_warmup`. One `train_one_epoch()` and one `evaluate()` helper reused by
      both the main run and the unseen-event runs (`evaluate` returns probabilities and predictions).
- [x] Each epoch: train loss (assert finite), val Macro F1. Keep the state_dict of the best val Macro F1 epoch in
      memory; record `best_epoch`. Plot train loss and val Macro F1 per epoch.

## Run on Colab (through `colab-mcp`)
`colab-mcp` is installed in Claude Code (local scope for this project). It only loads in a session started after
the install, which is the cook session.

1. Write the notebook locally and run the Colab setup cell's logic once locally to confirm it is a no-op there.
2. An opens https://colab.research.google.com, uploads `backend/notebooks/04_distilbert_finetune.ipynb`
   (File > Upload notebook), and sets Runtime > Change runtime type > **T4 GPU**.
3. Claude calls `open_colab_browser_connection`; An accepts the connection in the Colab tab within 60 seconds.
   The notebook editing and execution tools then appear.
4. Claude runs the cells in order, reading each output; on an error it fixes the **local** notebook first, then
   mirrors the same fix in Colab, so the two never drift.
5. After the export cell, An saves the zip and unzips it into `backend/` locally. An also downloads the executed
   notebook (File > Download > .ipynb) over `backend/notebooks/04_distilbert_finetune.ipynb`, so the repo keeps
   the outputs. Claude then diffs its code cells against the local version; only outputs should differ.
6. Keep the Colab tab open and active during training. If the runtime disconnects, rerun from the top (the VM
   disk is wiped).

**Local fallback** (Colab unavailable): same notebook in `ml-env` on MPS; first run downloads the DistilBERT
weights (about 268 MB).
```bash
cd "backend/notebooks" && /opt/anaconda3/bin/jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=ml-env --ExecutePreprocessor.timeout=-1 04_distilbert_finetune.ipynb
```
